# Expectation Decider

## 📌 Project Overview

Expectation Decider is a Python-based probability and statistical analysis project that uses a Student Performance Dataset to explore probability concepts and analyze relationships between different events.

The project demonstrates how probability and statistical techniques can be applied to student performance data using Python and Jupyter Notebook.

## 📂 Dataset

The project uses a synthetic dataset containing **500 student records**.

### Dataset Attributes

- `Student_ID` – Unique identifier for each student.
- `study_hours` – Number of hours spent studying.
- `attendance` – Student attendance percentage.
- `group_discussion` – Participation in group discussions.
- `previous_test_score` – Score obtained in the previous test.
- `final_exam_pass` – Indicates whether the student passed the final exam.

**Note:** The dataset is synthetically generated for educational and analytical purposes.

## 📊 Analysis Performed

### 1. Probability Basics
Explore fundamental probability concepts using student performance data.

### 2. Empirical and Theoretical Probability
Calculate empirical probability from observed data and explore theoretical probability using the Binomial Distribution.

### 3. Random Variable and Probability Distribution
Define a random variable representing the number of students who pass out of three randomly selected students.

### 4. Mean and Variance
Calculate the mean and variance of the Binomial Distribution.

### 5. Venn Diagram
Visualize the relationship between:
- Students studying more than 10 hours.
- Students with attendance above 80%.
- Students satisfying both conditions.

### 6. Contingency Table
Analyze the relationship between group discussion participation and final exam results.

### 7. Probability Calculations
Calculate:
- Joint Probability
- Marginal Probability
- Conditional Probability

### 8. Relationship Between Events
Examine whether group discussion participation and passing the final exam are independent, dependent, or mutually exclusive events.

### 9. Bayes' Theorem
Apply Bayes' Theorem to calculate the probability of passing the final exam given high attendance.

**Key Findings:**
- Probability of passing the exam: **81%**
- Probability of high attendance: **57.60%**
- Probability of passing given high attendance: **approximately 85.76%**

These findings describe patterns in the dataset and do not establish a cause-and-effect relationship.
